# standardize-skills-to-matt-pocock

## What it does

Prepares a reversible, human-reviewed patch candidate that brings one skill into the Matt-style compatibility contract.

## When to reach for it

Use it when a human explicitly requests skill standardization or a reviewable compatibility patch.

## Common questions

### Does it edit the source skill?

No. It preserves the source and emits a patch candidate.

### Can it install or synchronize a skill?

No. Installation is a separate approved transaction.

## It's working if

The output contains source hashes, rule IDs, evidence, and a review requirement, and the source file remains unchanged.
