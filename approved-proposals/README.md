# Approved repository proposals

These are the coordinator, index, metadata, and manifest files approved for the seven incomplete repositories supplied in the input list.

They are stored here as reviewable bundles because the authenticated GitHub account can write to this repository, but does not have write access to the original source repositories. The source repositories were not pushed to or changed remotely.

Each bundle contains:

- `proposal.json` — the evidence, component inventory, confidence levels, and digest.
- `proposal-report.md` — a readable summary.
- `files/` — the approved coordinator and index files, preserving the proposed repository paths.

The bundles are organized by source repository name and are committed to the `tools` branch of `ToolsForCodex`.
