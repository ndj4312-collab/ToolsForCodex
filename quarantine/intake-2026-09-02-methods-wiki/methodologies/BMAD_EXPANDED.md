# BMAD Expanded Methodology for ToolsForCodex

Source: `bmad-code-org/BMAD-METHOD` at `891c0abbc1128f318e098a566f925155022aef12`, MIT.

Use BMAD for:
- right-sized planning depth;
- durable product/architecture decisions;
- specialist perspectives on demand;
- correct-course routing on consequential surprises;
- evidence-backed epic retrospectives.

Planning depth:
- D0 Direct — known/reversible/narrow/obvious verification.
- D1 Brief — outcome, constraints, acceptance.
- D2 Spec — spec + tickets + verification.
- D3 Architecture — multi-surface/consequential, requires product/architecture/UX/security/eval lenses.

Evaluation:
- task outcome;
- process quality;
- capability lift versus a simpler baseline.
Preserve nulls/regressions. No method rule survives merely because it sounds rigorous.
