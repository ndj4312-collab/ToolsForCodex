# Derived Knowledge Router Prototype

This directory is **DERIVED | NON-CANONICAL**. It exists only to route ambiguous or cross-cutting questions toward authoritative ToolsForCodex sources with less discovery/context overhead.

Canonical repository and Notion sources always win. If the exact authoritative source is already known, bypass this wiki and read that source directly.

Files:
- `index.md` — compact human-readable concept-to-source routing map.
- `index.json` — machine-readable routing map.
- `knowledge-router.mjs` — prototype read-only router over the derived map.
- `BENCHMARK.md` — scoped routing benchmark and promotion threshold.

No autonomous canon mutation, silent refresh promotion, or `update_knowledge` capability is permitted by this prototype.
